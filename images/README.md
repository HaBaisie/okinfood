# Photos

Product photo: save as `images/products/<name>.jpg` using the file names in PHOTO-LIST.txt.
No edits to the code are needed. Missing photos show a plain grey tile.

Good product photos:
- White or light plain background, product centred, square crop (1000 x 1000 px).
- Shoot in daylight near a window. No flash, no clutter, no shadows from your hand.
- Branded items (Indomie, Peak, Milo): use a clear front shot of the real pack.
- Keep each file under 200 KB (use squoosh.app or tinypng.com).

Banner: `images/hero.jpg` (wide, about 2000 x 700 px, subject on the right side).
Category tiles: `images/categories/<category-slug>.jpg`, for example `naija-ingredients.jpg`, `rice-beans-and-staples.jpg`.
